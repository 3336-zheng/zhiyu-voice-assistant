# ADR-0001：Markdown 作为知识主数据

- 状态：已采用
- 日期：2026-08-04
- 更新：2026-10-14 —— 元数据存储由 SQLite 换成 MySQL，决策本身不变

## 背景

个人知识库需要长期可读、可导出，并避免被某个向量数据库或应用版本锁定。

## 决策

正文使用 UTF-8 Markdown 与 YAML Front Matter 保存；MySQL 管理查询友好的元数据和版本，ChromaDB / BM25 只保存派生索引。

数据库经历了 SQLite → MySQL 的迁移，但**这个决策与用哪个数据库无关**：正文始终在文件系统上，数据库只存元数据。迁移只影响元数据存在哪，不影响正文的可读性。

## 结果

- 用户可以直接读取、备份和迁移知识文件。
- 索引损坏或更换模型时可以全量重建——ChromaDB 与 BM25 都是可随时丢弃的派生数据。
- 文件与数据库属于两个资源，需要原子写入和失败补偿：数据库提交失败时恢复原 Markdown。
