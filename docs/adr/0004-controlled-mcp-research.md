# ADR-0004：受控 MCP 外部研究

- 状态：已采用
- 日期：2026-08-05

## 背景

本地 Wiki 可能缺少回答问题所需的资料。直接让 Agent 自动联网或动态调用任意 MCP 工具，会扩大提示注入、SSRF、凭证泄漏和未经确认写库的风险。

## 决策

外部研究只在本地证据不足后由用户显式触发。系统仅连接部署者配置的可信 stdio MCP Server，并只允许固定的搜索和抓取工具。外部来源经过公网 URL 校验、去重、截断和提示注入隔离后生成带引用草稿；草稿复用 Agent 待确认操作，通过 `PageService` 写入 Wiki。

研究任务、来源内容快照和页面来源关系保存到 SQLite。MCP 子进程只获得显式配置的环境变量，工具错误不回传 Server 输出或敏感配置。

## 结果

- 本地知识边界保持清晰，证据充分时不会调用 MCP。
- 外部研究具备来源追溯和可审计状态，不会自动污染知识库。
- 搜索能力依赖受信任 MCP Server；应用侧 URL 校验不能替代 Server 对重定向、DNS 重绑定和网络出口的控制。
- 外部研究增加一次用户确认和额外模型调用，以换取可控写入与来源完整性。
